# MyTracker

- `html+css+js/` — исходное автономное демо, оставлено без изменений.
- `TrackerWebApp/Client/` — пустая папка для будущего фронтенда.
- `TrackerWebApp/Server/` — Express 5 + TypeScript + PostgreSQL, REST API, миграции, тесты и коллекция Postman.

Запуск и описание API: [TrackerWebApp/Server/README.md](TrackerWebApp/Server/README.md).

Git не сохраняет пустые каталоги. После нового клонирования при необходимости создайте `TrackerWebApp/Client` вручную; в текущей рабочей копии папка создана и пуста.
