# Результат переноса — 04.09.2026

Весь действующий интерфейс `html+css+js` перенесён в существующую папку `TrackerWebApp/Client` на React JavaScript. Исходник не изменён. Новой серверной архитектуры или таблиц не добавлено. Последующая миграция `003_default_preferences.sql` задаёт тёмную тему и русский язык новым пользователям.

Перенесены вход, боковая и верхняя панели, доска/карточки, фильтры/поиск/статистика, очереди, обе формы просмотра задачи, CRUD, комментарии, журнал, админ-панель, имена/роли, настройки, переводы, таймеры, анимации и responsive CSS. Девять активных CSS-файлов скопированы побайтно; шрифты и иконки доступны локально. Данные поступают из настоящего API, а не из демо или localStorage.

Изменения по требованиям:

- Регистрация и ссылки на неё отсутствуют. Администратор создаёт пользователя в панели и самостоятельно передаёт email/пароль. Вход администратора при этом сохраняется.
- Backend получил административный `POST /api/users`, браузерную HttpOnly-сессию с проверкой Origin/CSRF и раздачу собранного `Client/dist`. Bearer API сохранён для существующих клиентов.
- Публичная регистрация запрещена. По последующей просьбе пользователя внешние способы входа полностью удалены; оставлен только логин и пароль.
- Экран входа и новые аккаунты используют тёмную тему и русский язык. Добавлена отдельная команда очистки `db:reset`, сохраняющая администратора и его пароль. Автоматического удаления при запуске нет.
- Исправлена обработка версии задачи после собственных комментариев, истёкшей сессии, конфликтов и сетевых ошибок. Черновики не теряются при ошибке сохранения.

Подключённые API: auth/login/me/logout, users/create/update, queues/create/delete, issues/create/update/delete, comments/create/delete, issues/stats, metadata, activity, settings. Подробная таблица и запуск: [README.md](README.md).

## Ограничения

После правок по очистке и входу повторно прошли сборки Client/Server, Server typecheck, 42 серверных теста, 14 основных UI-тестов и отдельный UI-сценарий пустого пространства (включая экран входа на компьютере и телефоне). Очистка проверена на временной базе с полным демо: осталось 1 администратор, 0 очередей, задач и комментариев; прежний пароль работает. Подключение к рабочей базе в окружении не настроено, поэтому её фактическая очистка пока не выполнена.

В проверенных сценариях переноса открытых ошибок нет. Внешний вход впоследствии удалён по просьбе пользователя. Docker недоступен на этой машине, его запуск не проверялся; Compose сервера по-прежнему собирает API отдельно.

Сохранены исходные ограничения интерфейса: горизонтальная прокрутка канбан-доски на узком экране, скрытые элементы верхней панели и отсутствие отдельной адаптации анимаций к reduced-motion. Самостоятельные UX-улучшения не вносились. Изменённые ранее демоданные из localStorage автоматически не импортируются в PostgreSQL.
